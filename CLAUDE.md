Beyond Coverage: Connectivity Intelligence Malaysia

MDIT 2026 Datathon entry. Submission deadline: 29 Nov 2026 (dashboard link + report + video). Full team plan: https://claude.ai/artifact/GcM5gN8sHf8mHFSRQcLftH

What we are building

A Streamlit dashboard that finds rural communities that are "covered" on paper but not truly connected, and ranks where connectivity investment should go first, which fix fits (fibre, tower, satellite), and at roughly what cost. Users: MCMC (JENDELA), Ministry of Communications, Ministry of Education, Sarawak/Sabah state governments. SDG 9.c (main), SDG 4.a and 4.4 (second).

Key contrast: network coverage of populated areas (mainly outdoor) 99.71% vs DOSM household access 90.7% rural (2025), and 1,180 of 5,362 schools in six states without fibre (Hansard, Dewan Rakyat, 11 Nov 2026; Sarawak 759). The two are different indicators (where the network reaches outdoors vs whether households are online), never a measured gap; always label 99.71% with facts.yaml 'label' ('Network coverage of populated areas (mainly outdoor)').

Hard rules
Never hardcode a statistic. Every number shown in the app or report is read from a file in data/. The only typed constants allowed are the cited headline figures above, kept in config/facts.yaml with their source URL.
Never invent or estimate missing data. If a download fails or a value is missing, stop and say so.
Keep raw downloads untouched in data/raw/. Cleaned outputs go to data/processed/, produced only by scripts in scripts/. Anyone must be able to rerun the pipeline from raw to processed.
Every dataset gets a short note in data/README.md: source, URL, date downloaded, licence, caveats.
Aggregated public data only. No personal data.
Label every estimate as an estimate (costs, weak-school flags, line-of-sight coverage).

Fixed-speed tests only come from homes that already have fixed broadband: always read speed together with DOSM access.

schools_connectivity.csv: 5,349 schools in the 6 states with district, fixed tiles/tests within 1 and 2 km, nearest fixed tile, mobile tests + speed within 2 km, likely_no_fibre (no fixed tile within 2 km; _1km variant), confidence (mobile tests within 2 km: high >=100, medium 20-99, low <20). ESTIMATE: validation vs Hansard is poor at state level (2 km: 786 vs 1,180, -33%; 1 km total -1.9% only by offsetting errors, e.g. Terengganu 83 vs 4). Present flags as a low-confidence screening list, always with the state-level error; never as a count of schools without fibre.

gap_index_districts.csv: 164 districts (Siburan, Membakut not indexed: no Ookla). CGI from access_gap (2025), mobile_speed + fixed_reach (Ookla 2026Q3, fixed_reach is a PROXY), low_income (2024; 2022 for Perlis + territories); ranks national + Sarawak with Dirichlet p05-p95; people_without_home_internet (ESTIMATE, household rate applied to individuals); students from MOE school list 2022 (enrolment file is by PPD, not district). gap_index_sensitivity.csv: equal weights, 1,000 Dirichlet runs, MOE rank range for small-sample districts. Only Sarawak's top 3 (Kanowit, Song, Tebedu) are stable; always show rank ranges.

settlements.csv / settlement_types_summary.csv (PROXIES and ESTIMATES; expert feedback from an MCMC officer, Nov 2026; name/title only if the team confirms permission): one row per rural settlement with mobile_quality (nearest Ookla mobile tile within 2 km: good >= 35 Mbps = JENDELA Phase 1 mean-speed target / weak / no_tests; many tiles have 1-3 tests), terrain (mean slope within 500 m, Terrain Tiles z12: flat < 5 deg, hilly, steep >= 15 deg), road (straight-line km to nearest motorable OSM road, tracks excluded: near <= 1, far, very far > 5 km), *_missing flags (never guessed; type U if a deciding input is missing, none today) and settlement_type by ordered rules A Network nearby -> B Larger unconnected village (>= tower break-even) -> E Good mobile signal nearby -> D Isolated or difficult terrain -> C Small village, reachable. Counts: Malaysia A 3,456, B 7, E 460, D 41, C 358; Sarawak A 778, B 0, E 205, D 23, C 208. Type cost ONLY with a cited unit cost: B tower, D satellite (both equal cost_main), E FWA retail plan (costs.yaml fwa, yes.my RM99/mth x 60); A and C 'not costed (no public cost source)'. The tower-vs-satellite screen (cost_main) is unchanged and still drives rankings and the budget planner. Wording: 'candidate technologies (screening)', never 'recommended'. Palette ui.TYPE_COLOURS (validated all-pairs on light; A/B/D reuse take-up/tower/satellite colours).

costing_clusters.csv / costing_districts.csv (ESTIMATES; method in docs/costing_method.md): one settlement per rural MOE school; households = Census 2020 rural households / rural schools (4 new Sarawak districts: parent values, split by 2026 population). Settlements with any Ookla fixed tile within 2 km = 'fixed network likely nearby: take-up gap' (PROXY): NO infrastructure cost, reported per district (80% of settlements, ~468k people); costed as fibre PoPs only in the upper bound. Others: tower if UNCONNECTED households (households x access gap, the ones the costs pay for) >= break-even (144.1 Residential / 228.3 Lite), else satellite: 7 towers, 859 satellite, none in Sarawak. Sensitivity rule_all_hh keeps the earlier all-households test (804 tower). Totals: main RM0.44bn (Sarawak 0.26), Lite 0.29 (0.17), upper bound 5.51 (1.41), rule_all_hh 1.73 (0.82). The story is 'what fix does each district need', not a value ranking: NEED (CGI) IS THE MAIN RANKING. Estimated beneficiaries per RM1m are close together for satellite-only districts (Sarawak top 15 ~266-310; nationally ~298-372; the 3 tower districts Pasir Mas, Bandar Baharu, Kinabatangan are higher), so small rank differences mean little. Take-up proxy caveat: the same 2 km fixed-tile proxy undercounted schools without fibre by ~33% vs Hansard (schools_validation.csv), so the take-up group is likely overstated and the main cost understated; the upper bound covers this. Metric = ESTIMATED BENEFICIARIES PER RM1m (rural people without home internet in planned settlements per RM1m; never call it 'value' or 'best value'); whole-district per RM1m is secondary; students per RM1m separate. Take-up wording: 'Our proxy suggests many rural settlements already have a fixed network nearby, so take-up support may matter as much as new infrastructure.' Always show the cost-screen caveat (equal households per rural school; towers and satellite are different services; not a full cost-benefit comparison). Never present solar-hybrid or fibre extension as recommendations; fibre PoPs are an upper-bound cost sensitivity only. JENDELA's ~80 residents/site is far below break-even: present the rule as a cost screen.

Method
Clean and merge by state and district.
Schools come with MOE coordinates (no geocoding); attach Ookla speeds from tiles within 1-2 km.
Flag "likely weak" schools: speeds far below fibre level (300-800 Mbps) or almost no tests nearby; add a confidence level.
Validate: sum flags per state, compare with the six Hansard totals; report the error.
Connectivity Gap Index per district: CGI_d = sum_i(w_i * S_di), min-max normalised indicators (district household access gap, speed gap, share of likely weak schools, population affected, low income). Weights documented in config/weights.yaml; include a sensitivity check.
Two rankings: need (CGI) and value (people and students helped per estimated RM).
Rule-based fix recommender; costs from cited sources in config/costs.yaml.
